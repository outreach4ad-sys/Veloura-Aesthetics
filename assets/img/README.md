# Brand assets

Drop the real files here with these exact names — the code already points at them:

| File | Purpose | Status |
|---|---|---|
| `logo.png` | Main Veloura Tec logo (circular copper emblem). Used in the header, footer, admin bar, login card and as the default social share image. Transparent PNG, ~512×512. | **Supplied by client — upload the PNG to this path.** |
| `favicon.png` | Browser tab icon, 48×48 or 64×64 PNG, cropped tight to the emblem. | Pending |
| `og-default.jpg` | Fallback social share image, 1200×630. Optional — falls back to `logo.png`. | Pending |
| `placeholder.svg` | Neutral fill shown when a product has no image yet. | Included |

The logo path is also overridable from **Admin → Settings → `site_logo`**, so it can
be swapped later without editing code.
