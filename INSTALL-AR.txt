المتطلبات: PHP 8.1 أو أحدث (يُفضّل 8.2) + قاعدة بيانات MySQL/MariaDB
الإضافات المطلوبة: pdo_mysql - mbstring - fileinfo - gd


--- 1) إنشاء قاعدة البيانات -----------------------------------------

لوحة hPanel  ->  Databases  ->  MySQL Databases
1. أنشئ قاعدة بيانات جديدة.
2. أنشئ مستخدماً وكلمة مرور قوية، وامنحه كل الصلاحيات عليها.
3. احتفظ بالاسم واسم المستخدم وكلمة المرور، ستحتاجها في الخطوة 3.


--- 2) استيراد الجداول ----------------------------------------------

hPanel  ->  phpMyAdmin  ->  اختر قاعدة البيانات  ->  تبويب Import
ارفع الملف:  database/schema.sql   ثم اضغط Go

النتيجة المتوقعة: 10 جداول + 23 إعداداً + 9 أقسام + شريحة هيرو واحدة.

تنبيه: لا تُعد تشغيل هذا الملف على قاعدة بيانات تحتوي على بيانات،
لأنه يبدأ بأوامر DROP TABLE وسيحذف المحتوى الموجود.


--- 3) رفع الملفات --------------------------------------------------

ارفع *محتويات* هذا الأرشيف (وليس المجلد نفسه) داخل public_html

أسهل طريقة: File Manager  ->  Upload  ->  ارفع ملف ZIP  ->  Extract

مهم جداً: فعّل إظهار الملفات المخفية
(File Manager -> Settings -> Show hidden files)
وتأكد من رفع ملفات .htaccess الأربعة:

  public_html/.htaccess
  public_html/uploads/.htaccess   <-- الأهم: يمنع تنفيذ أي كود داخل مجلد الرفع
  public_html/app/.htaccess
  public_html/database/.htaccess


--- 4) ملف الإعدادات ------------------------------------------------

انسخ   app/config.sample.php   إلى   app/config.php
ثم عدّل القيم التالية:

    'env'      => 'production',
    'base_url' => 'https://veloura-tec.com',
    'db' => [
        'host' => 'localhost',
        'name' => 'اسم_قاعدة_البيانات',
        'user' => 'اسم_المستخدم',
        'pass' => 'كلمة_المرور',
    ],

ملف app/config.php يحتوي على بيانات حساسة — لا تشاركه مع أحد.


--- 5) إنشاء حساب المدير --------------------------------------------

الطريقة الأفضل عبر SSH (hPanel -> Advanced -> SSH Access):

    cd ~/public_html
    php database/seed_admin.php "الاسم" "email@veloura-tec.com" "كلمة-مرور-طويلة"

إن لم يتوفر SSH:
1. افتح public_html/.htaccess وعطّل مؤقتاً هذا السطر بإضافة # في أوله:
       RewriteRule ^(app|database|storage|includes)/ - [F,L]
2. افتح في المتصفح:
       https://veloura-tec.com/database/seed_admin.php
3. املأ النموذج.
4. أعد السطر كما كان (احذف #).

*** بعد الانتهاء احذف الملف database/seed_admin.php من السيرفر فوراً ***
(البرنامج يرفض العمل مرة ثانية، لكن حذفه أأمن.)


--- 6) الصلاحيات ----------------------------------------------------

    uploads/  وكل مجلداته   ->  755
    storage/                ->  755
    app/config.php          ->  644


--- 7) تفعيل HTTPS --------------------------------------------------

hPanel  ->  Security  ->  SSL  ->  فعّل شهادة Let's Encrypt المجانية
ثم فعّل خيار Force HTTPS.

بعد التأكد من عمل HTTPS، افتح public_html/.htaccess وأزل # من سطر:
    Header always set Strict-Transport-Security ...


--- 8) إصدار PHP ----------------------------------------------------

hPanel  ->  Advanced  ->  PHP Configuration  ->  اختر 8.2

من تبويب PHP options اضبط:
    upload_max_filesize = 40M
    post_max_size       = 48M
    max_execution_time  = 120
    display_errors      = Off

ومن تبويب PHP extensions تأكد من تفعيل:
    pdo_mysql - mbstring - fileinfo - gd


--- 9) شعار الموقع --------------------------------------------------

ارفع ملف الشعار باسم:   assets/img/logo.png
وأيقونة المتصفح باسم:   assets/img/favicon.png

الشعار يظهر تلقائياً في الهيدر والفوتر ولوحة التحكم وصفحة الدخول.
ويمكن تغيير مساره لاحقاً من: لوحة التحكم -> Settings -> site_logo


--- 10) الدخول وإكمال الإعدادات -------------------------------------

    https://veloura-tec.com/admin/login.php

لوحة التحكم ستعرض لك قائمة بكل الإعدادات التي ما زالت تحمل
[PLACEHOLDER: ...] — استبدلها بالبيانات الحقيقية:

    - رقم واتساب (أرقام فقط مع رمز الدولة، مثال: 970599123456)
    - البريد الإلكتروني
    - رقم الهاتف
    - العنوان
    - شروط الشحن والإرجاع

هذه القيم مخفية عن الزوار إلى أن تستبدلها، فلا يظهر أي نص غير حقيقي.
